# 지구과학 시뮬레이션 실험실

고등학교 지구과학 수업용 시뮬레이션 모음 사이트입니다.

## 폴더 구조

```
index.html                 메인 페이지 (단원별 카드 목록)
css/style.css              모든 페이지가 함께 쓰는 디자인
astronomy/moon-phase.html  달의 위상 변화
astronomy/kepler.html      케플러 제2법칙
template/                  새 시뮬레이션을 만들 때 복사해서 쓰는 틀
```

## 새 시뮬레이션 추가하기

1. `template/simulation-template.html`을 복사해 단원 폴더에 넣고 영어 이름으로 바꿉니다.
2. 파일 안의 ①~⑤ 표시 부분을 채웁니다.
3. `index.html`에서 해당 단원에 카드를 추가합니다.
4. GitHub 저장소에 업로드하면 몇 분 뒤 사이트에 반영됩니다.
