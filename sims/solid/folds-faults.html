생각 열기: 암석 요리사가 만드는 요리는?
암석에 높은 열과 압력을 가하면 어떤 일이 생길까?
Q암석을 압력솥에 넣고 뜨겁게, 세게 누르면 녹아 버릴까?
녹지 않고 고체 상태 그대로 광물과 조직이 바뀔 수 있어요. 이것이 변성 작용이에요.
녹아 버리면? 그건 마그마가 되어 화성암으로 가는 길이에요.
변성 작용: 고체 상태에서 암석이 변해요
생성 당시와 다른 온도나 압력을 겪으면 광물의 조성이나 조직이 변화해요.
A 광역 변성 작용판이 섭입하거나 충돌하는 지역 → 온도와 압력 상승 → 넓은 지역에 걸쳐 변성
B 접촉 변성 작용마그마가 관입 → 열과 휘발 성분 → 마그마와의 접촉부에서 변성
휘발 성분: 대부분 H₂O와 CO₂, 마그마에 보통 3~5 % 내외 포함
두 변성 작용은 일어나는 조건이 달라요
접촉 변성: 낮은 압력 + 높은 온도 / 광역 변성: 넓은 범위의 온도·압력
그래프의 가로축은 온도, 세로축은 아래로 갈수록 압력(깊이)이 커져요.
위쪽의 얇은 띠: 접촉 변성 작용 (얕은 곳, 고온)
가운데 넓은 영역: 광역 변성 작용
화강암의 용융 곡선을 넘으면 → 마그마(녹음) → 더 이상 변성 작용이 아니에요.
시뮬레이션변성 작용 실험실: 온도와 압력을 바꿔 봐요
그래프 위의 점을 드래그해 온도·압력을 정하고, 암석이 어떻게 변하는지 관찰해요.

빠른 이동

※ 교과서 그림 25를 바탕으로 영역을 단순화한 개념 모형이에요.
접촉 변성 작용으로 생긴 암석: 혼펠스와 대리암
마그마의 열을 받아 치밀하고 단단한 암석이 돼요.
그림 26 혼펠스(셰일이 접촉 변성), 그림 27 대리암(석회암이 접촉 변성)
셰일 → 혼펠스
사암 → 규암
석회암 → 대리암
재결정 작용: 광물 입자가 커지고 새 광물이 생겨요
고온·고압에서 오랜 시간 → 새 변성 광물이 생기거나 광물 입자가 커져요.
처음 암석의 조직 → 재결정 작용 → 변성된 암석의 조직
광물 입자가 커지고 서로 맞물려 치밀하고 단단해져요.
접촉 변성암에는 엽리가 나타나지 않아요.
광역 변성암에는 엽리가 생겨요
압력이 작용한 방향에 직각 방향으로 광물이 나란히 배열 = 엽리
셰일의 변성 작용 (변성 작용이 커질수록 →)
편리: 변성 작용 초기, 줄무늬가 얇아요.
편마 구조: 변성이 더 진행, 줄무늬가 두꺼워요.
셰일 → 점판암(슬레이트) → 천매암 → 편암 → 편마암
변형 구조 ① 습곡: 횡압력으로 휘어진 지층
지하 깊은 곳 고온·고압 환경에서 양쪽에서 미는 횡압력을 받아 휘어져요.
습곡축: 습곡 중앙의 축
배사: 위로 볼록 / 향사: 아래로 볼록
지표에 노출되면 배사 중심부에 가장 오래된 암석, 향사 중심부에 가장 젊은 암석
산봉우리는 모두 배사일까?
지층이 휘어진 모양과 지표의 높낮이는 다를 수 있어요.
Q위로 볼록한 배사가 늘 산봉우리가 될까?
아니요. 산봉우리와 주변의 침식 정도에 따라 향사 구조가 산봉우리로 나타날 수도 있어요.
변형 구조 ② 단층: 끊어져 어긋난 지층
지표 부근의 암석층은 힘을 받으면 끊어지기 쉬워요.
단층면: 지층이 끊어진 면
단층면이 경사져 있을 때 윗부분 = 상반, 아랫부분 = 하반
절리와 단층은 비슷해 보이지만, 절리는 틈을 따라 양쪽 암석이 어긋나지 않아요.
단층의 종류: 상반이 어떻게 움직였을까?
정단층 · 역단층 · 주향이동 단층
정단층장력 → 상반이 중력에 의해 아래로
역단층횡압력 → 상반이 위로
주향이동 단층수평 방향의 힘 → 두 암반이 수평으로 이동
판의 경계에 따라 생기는 변형 구조가 달라요
발산형 · 보존형 · 수렴형 경계
발산형해령·열곡대: 장력 → 정단층
보존형수평으로 어긋남 → 변환 단층(주향이동 단층)
수렴형해구·습곡 산맥: 횡압력 → 습곡, 역단층
변동대에서는 열과 압력으로 다양한 변성암과 지질 구조가 나타나요.
우리나라의 변성암 지형
한반도의 암석은 여러 번의 지각 변동과 변성 작용을 겪었어요.
(가) 백령도 장촌 해안: 선캄브리아시대 규암층이 횡압력 → 습곡과 단층
(나) 가평 명지계곡: 선캄브리아시대 호상 편마암 + 돌개구멍
(다) 인천 대이작도: 한반도에서 가장 오래된 암석, 약 25억 년 전 변성된 혼성암
(라) 문경: 고생대 석회암이 지각 변동 → 습곡 등 변형 구조
혼성암: 용융점 부근에서 변성과 용융이 함께 일어나 변성암과 화성암의 특징을 모두 가진 암석
해 보기) 암석의 순환 과정 추론하기
그림은 순환 과정의 일부예요. 빠진 화살표는 무엇일까?
사암(퇴적암) → 변성 → 규암(변성암)
화강암(화성암) → 풍화·침식 → 퇴적물 → 퇴적암
추가할 화살표 예: 화성암 → 변성암(변성), 퇴적암 → 퇴적물(풍화·침식·퇴적), 퇴적암·화성암 → 마그마(용융), 변성암 → 변성암(변성)

일어날 수 있는 과정

암석은 지구시스템 안에서 끊임없이 순환해요
원동력: 지구 내부 에너지와 태양 에너지
지구 내부 에너지화성암과 변성암을 형성 (용융, 냉각, 변성)
태양 에너지풍화·침식 작용과 퇴적물의 이동
순환은 한 방향이 아니라 다양한 경로로 계속 반복돼요.
용융이 일어난 뒤 결정이 만들어지면 변성암이 아니라 화성암이에요. (변성 작용은 고체 상태의 변화)
