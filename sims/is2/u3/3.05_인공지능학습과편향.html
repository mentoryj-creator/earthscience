인공지능 분리배출 로봇

재활용 선별장의 인공지능 로봇은 센서로 잰 무게와 반짝임만 보고 플라스틱과 캔을 구분합니다. 컨베이어 벨트로 오는 쓰레기에 정답(이름표)을 붙여 로봇을 학습시키고, 데이터가 치우치면 인공지능이 어떤 실수를 하는지 확인해 보세요.

미션
이름표를 붙인 데이터 25개 이내로, 시험 데이터 정확도 90 % 이상인 로봇을 만드세요.처음에는 A 동네 쓰레기만 들어옵니다. 오른쪽의 ‘찌그러지고 칠한 캔’ 정확도를 잘 보세요!

인공지능은 어떻게 배울까

  1. 인공지능은 사람의 학습, 추론 능력을 컴퓨터로 구현한 기술이다. 인공지능 로봇은 주변을 인식하고 스스로 판단해 움직인다.
  2. 기계 학습에서는 정답이 붙은 많은 데이터(학습 데이터)에서 규칙을 스스로 찾는다.
  3. 학습에 쓰지 않은 새 데이터(시험 데이터)로 얼마나 잘 맞히는지 확인해 성능을 평가한다.
  4. 학습 데이터가 한쪽으로 치우치면(편향) 인공지능은 처음 보는 경우를 틀리기 쉽다. 이름표가 틀려도 잘못 배운다.
  5. 그래서 다양하고 정확한 데이터를 모으고, 인공지능의 판단을 사람이 점검하는 것이 중요하다(인공지능 윤리).
생각해 볼 문제인공지능 로봇이 잘못 판단해 피해가 생기면 누구의 책임일까? 만든 사람, 데이터를 준 사람, 사용한 사람, 아니면 로봇?

수업용 질문

  1. A 동네 쓰레기로만 학습시켰을 때 전체 정확도와 ‘찌그러지고 칠한 캔’ 정확도는 각각 얼마였나요? 차이가 나는 까닭은 무엇인가요?
  2. ‘여러 동네 쓰레기’로 데이터를 모으자 판단 영역이 어떻게 바뀌었나요?
  3. 이름표를 일부러 하나 틀리게 붙여 보세요. 이웃 1개일 때와 7개일 때 영향이 어떻게 다른가요?
  4. 얼굴 인식, 채용, 대출 심사 등에서 데이터 편향이 일으킬 수 있는 문제를 조사해 보세요.
  5. 인공지능 로봇을 사회에서 안전하게 쓰기 위해 필요한 규칙(과학 윤리)을 모둠별로 만들어 보세요.

센서 값과 쓰레기 종류는 학습용으로 만든 가상의 데이터입니다. 실제 선별 로봇은 카메라 영상 등 훨씬 많은 특징을 씁니다.
