GitHub 연결 연결 안 됨

토큰은 어떻게 만드나요?
  1. GitHub에 로그인 → 오른쪽 위 프로필 사진 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Token name은 아무 이름, Expiration은 원하는 기간(예: 1년)
  4. Repository access: Only select repositories → 이 사이트 저장소 하나만 선택
  5. Permissions → Repository permissions → Contents를 Read and write로
  6. Generate token → 나온 값을 복사해 위 칸에 붙여 넣기 (한 번만 보여 주니 따로 안전하게 보관)
토큰은 이 브라우저에서 GitHub로만 전송되고 사이트 파일에는 저장되지 않습니다. 연결하지 않아도 아래에서 sims.js 내려받기로 저장한 뒤 직접 올릴 수 있습니다.
